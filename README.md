# 🏦 Bank Analysis | Power BI Dashboard

An interactive, 6-page Power BI dashboard analyzing a bank's customers, transactions, loans, and support calls, built end to end: data cleaning, data modeling, DAX measures, and visual storytelling.

## 📌 Key Numbers
| Metric | Value |
|---|---|
| Customers | 5,000+ |
| Transactions | 20K (~$100M) |
| Total Balance | $255M |
| Loans | 2,600 (~$644M) |
| Support Issues | 3,100 (49% solved) |

## 📊 Dashboard Pages
1. **Overview**: headline KPIs, balance by account type, loan status, top states by loan amount
2. **Customers**: account holders, active vs. dormant accounts, new customers over time
3. **Transactions**: amount by account type, quarterly trend, transaction types
4. **Loans**: loan amount by type, loan status, loans by quarter, card types
5. **Support Calls**: issues by type and state, solved vs. unsolved, issues by day
6. **Loan Tracking**: loan start and end dates with active/ended status

## 💡 Key Insights
- Loans are spread almost evenly across Car, Personal, Home, and Education; about 71% of the loan value is still active.
- Only 1,689 of 5,100 accounts are active, so about two-thirds are dormant.
- Monthly transaction activity trends downward.
- Only 49% of 3,100 support issues were resolved, which makes support the biggest area for improvement.

## 🧹 Data Notes
- The raw customer file had 5,050 rows; 50 were dummy/manual records, so customer counts need care.
- The "Army" value in the State column groups military addresses, not a real state, so it is treated separately in geographic views.
